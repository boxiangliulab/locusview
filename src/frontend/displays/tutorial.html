Tutorial

Start with Search data to find a gene or variant across QTL contexts and GWAS traits. Select a QTL phenotype to open its LocusZoom plot in Data Browser. You can also open Data Browser directly to search a region or compare multiple datasets. For scripts, see Request data from the API.

1. Search dataEnter a gene symbol, Ensembl ID, rsID, or chromosome position. Adjust the p-value threshold if needed.
2. Choose a phenotypeClick a QTL phenotype in the results table. Data Browser opens with its dataset, context, and locus selected.
3. Explore the plotThe selected phenotype's LocusZoom plot loads automatically. Its blue badge shows the QTL type; the title shows source project ID, context, and phenotype.

Browse a region or compare datasets

In Data Browser, select QTL contexts, GWAS traits, or both. Choose Gene, Region, or Variant, enter a locus, and click Run Query. GWAS plots appear immediately; check rows in the QTL results table to draw individual phenotype plots. A variant search in Search data includes GWAS results, but GWAS rows have no phenotype link.

Request data from the API

Everything the Search data page shows is also available as JSON at /api/search-data, so you can fetch it from Python (or any HTTP client) with the same search terms.

Parameters

ParameterRequiredMeaning
qyesGene symbol (TP53), Ensembl ID (ENSG00000141510), rsID (rs1042522), or position (chr17:7676154).
pnop-value threshold: only associations with a p-value below it are returned. Default {{ default_p }}; any number between 0 and 1 (1 returns everything).
datasetsnoLimit the search to specific datasets, comma-separated, e.g. qtl:1,qtl:5,gwas:1. Default: all datasets.

Example (Python)

import requests
import pandas as pd

base = "https://your-locusview-host"
r = requests.get(f"{base}/api/search-data", params={"q": "TP53", "p": {{ default_p }}}, timeout=60)
r.raise_for_status()
data = r.json()

print(data["type"], data["n_contexts"], "contexts,", data["n_rows"], "rows")

# The same table as the Search data page, row for row
df = pd.DataFrame(data["rows"])

Try it in the browser: /api/search-data?q=TP53&p={{ default_p }} · interactive reference: /docs

Response

  • type is "gene" or "variant"; gene / variant describe what was resolved (symbol, Ensembl ID and coordinates, or chromosome, position and rsID).
  • datasets_searched and datasets_failed (could not be searched in time — retrying usually works) summarize the search.
  • rows is exactly the table on the Search data page — same rows, same order, same columns: gene searches context, dataset, type, phenotype, lead_snp, variant, pvalue, beta; variant searches context, dataset, type, phenotype, pvalue, beta (phenotype is null for GWAS rows). p-values and β come back at full precision; the page only rounds them for display.
  • n_contexts and n_rows count the contexts and table rows.
  • Gene searches cover QTL only (GWAS has no gene concept); variant searches cover QTL and GWAS.
  • Errors return {"query": ..., "error": ...} with status 400 (missing q, invalid p, unrecognized input, or a region — use the Data Browser for regions) or 404 (unknown gene or rsID).
